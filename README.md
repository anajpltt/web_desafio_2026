# Desafio Final de R 2026: Análise Integrada de Genótipos de Linhaça

Site em Quarto com a resolução do desafio final da disciplina de Introdução ao R e os scripts das aulas.

Site publicado: https://anajpltt.github.io/web_desafio_2026/

## Estrutura

| Pasta/arquivo | Conteúdo |
|---|---|
| `index.qmd`, `about.qmd` | páginas inicial e "sobre" |
| `desafio/` | orientações do desafio e resolução |
| `aulas/` | scripts das aulas 1 a 6 |
| `dados/` | planilhas usadas nas análises |
| `images/` | imagens das páginas |
| `docs/` | site renderizado (gerado pelo Quarto; não editar) |
| `_quarto.yml`, `styles.css` | configuração e estilo do site |

## Como reproduzir

1. Abra `Desafio_2026.Rproj` no RStudio.
2. Instale os pacotes `rio` e `tidyverse`.
3. Renderize o projeto (aba **Build > Render Website**).
